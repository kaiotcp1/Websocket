# 3D model attribution

`webxr-hand-left.glb` and `webxr-hand-right.glb` come from the
[Immersive Web WebXR Input Profiles](https://github.com/immersive-web/webxr-input-profiles)
project and are distributed under the MIT license.

The assets expose the standardized WebXR hand joints. The application maps
MediaPipe landmarks to these joints in `src/components/ChoiceScene.jsx`.
